# Sharey

供研究组自行部署、以成员自己的 AI Agent 为入口的项目协作平台。

成员的 Agent 将选定的本地材料和记忆编译成只读研究节点；队友的 Agent 通过项目概览查找节点、获取材料与完整 Skill，继续研究。节点通过派生关系组成 DAG，支持分支与汇合。

首版入口为 Sharey Skill 与 CLI，连接研究组自行部署的服务。私人内容保留在本地；明确发布的内容在项目内共享。
