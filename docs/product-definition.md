# Sharey：1 小时 MVP 产品定义

状态：产品定义已确认，进入可实施状态。当前完成产品定义文档，尚未实现或运行。

## 产品定位

Sharey 是供研究组自行部署、以成员自己的 AI Agent 为入口的项目协作平台。它将成员选定的本地材料和 Agent 记忆编译成可共享、可接续的研究节点，让队友的 Agent 获取项目上下文与 Skill，继续研究。

## 核心使用闭环

1. 研究组部署 Sharey，建立项目。
2. 成员通过自己的 Agent 和 Sharey Skill，选定本地材料与记忆，编译并发布研究节点；可同时分享参考材料和完整 Skill。
3. 队友的 Agent 查询项目概览，定位并读取节点、材料与 Skill，回答成员的问题或继续工作。
4. 新进展发布为新节点，关联一个或多个已有节点，形成分支与汇合。

首版采用 **Sharey Skill + CLI + 自托管服务**，面向能够执行本地命令的 Agent。编译与研究工作由成员的 Agent 完成。

## 信息模型

| 对象 | 定义与约束 |
| --- | --- |
| 项目 | 组织共享研究节点、参考材料与 Skill 的范围。 |
| 来源材料（sources） | 已发布的只读参考资料，例如参考文献。研究过程中演进的工作材料归入节点。 |
| 研究节点（records 中的节点） | 一次发布的研究状态：标题与短摘要、研究记忆、选定文件的副本、贡献者、发布时间、父节点，以及相关来源材料与 Skill 的引用。 |
| 派生关系 | 表示新节点基于哪些已有节点形成。允许多个父节点；发布时只能引用已存在的节点，形成 DAG。汇合内容由发布者的 Agent 整理。 |
| Skill | 完整的 Skill 目录，保留指令、脚本、参考资料、模板及其相对引用。 |
| 项目概览（INDEX） | 由节点摘要、派生关系及资产索引生成的导航视图；说明项目目标、节点结构、节点内容、贡献者与时间，以及来源材料和 Skill 的位置。 |

节点发布后只读。本地文件变化不影响已发布节点；进展与修订发布为新节点。节点包含选定材料的快照，父节点关系提供继续浏览的路径。

INDEX 与节点读取使用同一套节点信息，不另行维护一份研究历史。首版不以短中长期为目录，也不实施自动记忆迁移或自动形成团队共识。

## Agent 与成员如何使用

Agent 可以查询项目概览，列出和读取节点、来源材料、Skill，获取具体文件，以及发布节点和完整 Skill。读取范围是项目所有已发布内容，获取一个节点不会将访问范围限制在该节点。

成员通过自己的 Agent 查看材料、理解 DAG、查找 Skill。Agent 可以用查询结果回答、画图，或临时生成工作台。首版交付查询与获取能力；共享网页工作台、持续更新的看板和图形编辑器属于后续产品范围。

团队 Wiki 不列入本次 MVP。当前通过 INDEX 提供项目入口，通过研究节点保存研究状态，通过成员自己的 Agent 按需解释和整理。后续若需要稳定的团队阅读页面，可从节点生成带来源的阅读视图；本次不增加独立 Wiki 编辑、维护与更新流程。

## 共享边界与部署

- 私人内容保留在本地；成员明确要求分享的内容才进入指定项目。
- 项目成员可以读取该项目所有已发布内容。
- 已发布材料与节点数据应持久保存，服务重启后仍可读取。
- 服务可由研究组自行部署；首个验收可在一台机器运行服务、由两个成员环境访问。
- 首版以项目共享访问凭证表示项目成员资格。持有凭证的成员及其 Agent 可以读取和发布该项目内容；不引入成员注册、登录与角色管理。贡献者名称是发布者提供的署名。

## 1 小时范围

完成一个自托管服务、一套 CLI、一份 Sharey Skill，以及一个可以演示上下文复用和 Skill 复用的研究样例。优先完成项目概览、对象列出与读取、文件获取、完整 Skill 分享，以及带多父节点的新节点发布。

## 验收标准

使用一个小型研究样例，完成以下完整路径：

1. 成员 A 的 Agent 将选定材料和研究记忆编译为节点，发布一份参考资料和一个可执行的完整 Skill。
2. 成员 B 的另一种 Agent 在没有 A 原始聊天历史的情况下，通过概览找到相关节点，正确说明研究目标、已有进展和下一步，并指出所用记录或材料。
3. B 获取完整 Skill，并用其配套资源完成一个最小任务；只列出或下载 Skill 不算运行成功。
4. 发布两个分支节点，再发布一个基于两个分支的节点；项目概览准确表达分支与汇合。
5. A 修改本地材料后，旧节点内容不变；未选中的私人文件未被发布；重启服务后已发布内容仍然可读。

实际验收记录需要区分文件/CLI检查、单 Agent 运行与跨厂商 Agent 运行。当前尚未执行上述验收。
